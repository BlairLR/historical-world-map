## U. 变音符号折叠的**危险性**验证

第四部分 P 节列出 5 组变音折叠合并，其中若干组是**不同实体**：

| 折叠 key | 成员 | 各成员年份 | 判定 |
|---|---|---|---|
| `han` | `Han` / `Hän` | 前1,100,200 / 1492 | ❌ **不同实体**：`Han` = 汉朝（前200–300 等），`Hän` = 阿拉斯加 Hän 阿萨巴斯卡人 |
| `sami` | `Sámi` / `Sami` | 200,800,1100,1200,1279,1400,1492,1500,1530 / 900 | ✅ 同一实体（Sámi 的两种拼写） |
| `maori` | `Maori` / `Māori` | 1279,1300,1400,1492,1500,1650,1700,1715,1815 / 1783,1800,1880,1900 | ✅ 同一实体（Māori 的两种拼写） |
| `awa` | `Awá` / `Ãwa` | 1492 / 1492 | ⚠️ **疑似不同实体**：`Awá`（巴西）vs `Ãwa`（哥伦比亚） |
| `chinese warlords` | `Chinese Warlords` / `Chinese warlords` | 1920,1930 / 1938 | ✅ 同一实体（仅大小写差异，主脚本已合并） |

> 结论：变音符号折叠**不能盲用**——`Han`/`Hän` 会被错误合并。任何折叠规则都必须经过逐组人工确认。

## V. 纯空白 NAME 的要素（附带发现）

NAME 字段的第 3 个合并组不是名字，而是**纯空白字符串**：

| NAME（原文） | 长度 | 年份 | SUBJECTO | 当前颜色 |
|---|---|---|---|---|
| `"      "` | 6 | 前5000 | `Cardial Ware culture` | `#c66c99` |
| `"           "` | 11 | 700 | `Bega` | `#6c72c6` |
| `"       "` | 7 | 1815 | `United Kingdom of Netherlands` | `#cdcd9a` |

- 由于这 3 个要素的 `SUBJECTO` 均有效，`SUBJECTO \|\| NAME` 取到的是 SUBJECTO，**color key 未受影响**（实测 color key 中纯空白项 = **0**）。
- 另有 **3 个要素的 NAME 是空字符串 `""`**。
- 影响面：当前不影响配色；但**未来做国家搜索 / 国家详情 / tooltip 时必须在 `trim()` 后判空**，否则会出现"名字是一片空白"的搜索结果。
