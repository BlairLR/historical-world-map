## §0 摘要（10 条最重要的调查结果）

1. **[A] Identity 系统的产出规模**：54 个上游快照 → 归一化 key **2,887** 个（§1.5 `manifest.identity.splitKeys = 136` 为被空档切分的 key 数）→ 历史政权实体 **3,057** 个（`entities.json` 记 3,056 个 + 合成实体 `UNNAMED`）；其中**手工实体 56** 个、自动实体 3,000 个。冻结颜色注册表 `data/identity/colors.json` 有 **3,097** 条，年份文件里实际出现的不同颜色值 **2,480** 个。
2. **[A] 颜色是 `entityId` 的函数，且链路无分叉**：`properties.color` 与 `entities.json` 中同 `entityId` 的 `color` **不一致的 feature = 0**（54 个文件、17,438 个 feature 全量比对）。也就是说「一个 entityId 在任何年份都是同一个颜色」在当前产物中严格成立。
3. **[A] 40.4% 的 feature 没有任何可用 key**：`NAME` 与 `SUBJECTO` **同时为空或空串的 feature = 7,046 / 17,438（40.4%）**，全部归入合成实体 `UNNAMED`（中性灰、不进 `entities.json`、不进颜色注册表）。这是「上层是否有实体语义」的最大缺口。
4. **[A] 属性冗余度很高**：`NAME` = `SUBJECTO` = `PARTOF` = `ABBREVN` 四者归一化后完全相同的 feature = **8,868（50.9%）**；`SUBJECTO` = `PARTOF` 的 feature = **9,686**。四个字段在多数 feature 上是同一个字符串的复制。
5. **[A] key 派生规则是 `SUBJECTO || NAME`（SUBJECTO 优先）**（[B] 见 `scripts/build-data.mjs:154`）。因为该优先级，「同一个多边形属于谁」既可能表现为 `SUBJECTO=殖民地本国名`，也可能表现为 `SUBJECTO=宗主国名`，两种形态在不同年份混用（§3、§4 有逐年证据）。
6. **[A] 同一 `(year, raw key)` 下可以有多达 25 个不同 `NAME`**：≥2 个不同 NAME 的组 **137** 个、覆盖 **537** 个 feature（3.1%）。极端样例：**1945 年 raw key = `United Kingdom` 的 25 个 feature 有 25 个不同 NAME**（本土 + Jamaica + Sierra Leone + Tanganyika + N. Rhodesia + Nyasaland + …），**全部 25 个当前都是同一个 `entityId = UK-UNITED-KINGDOM`**；1945 年 raw key = `France` 的 22 个 feature 同理全部是 `auto:france`。
7. **[A] 英国在本项目中至少存在 6 个互不相同的 raw key**：`uk`（1783/1800）、`united kingdom`（14 个快照年）、`united kingdom of great britain and ireland`（8 个快照年）、`great britain`（1878/1880）、`england`（7 个快照年）、`england and ireland`（4 个快照年）。其中 `uk`(1800) 的 6 个 feature 在 `SUBJECTO` 层面混合了主权国自身、殖民地（`British Guiana`）与**君合国**（`Hanover`、`Kingdom of Ireland`），还有一个 `Mecklenburg-Strelitz`。当前 `uk` / `united kingdom` / `united kingdom of great britain and ireland` **三者被同一个手工实体 `UK-UNITED-KINGDOM` 认领**，而 `great britain` / `england` / `england and ireland` 各有独立的 `auto:` 实体。
8. **[A] 美国的三个 raw key 现在被同一实体认领**：`united states`（10 年）、`united states of america`（5 年）、`usa`（1 年，1945）→ 全部 `US-USA`。1945 年 `USA` key 下的 5 个 feature 是 `Japan (USA)` / `Germany (USA)` / `United States Virgin Islands` / `United States` / `Korea (USA)`；1938 年 `United States` key 下的 3 个是 `Philippines` / `United States` / `Guam` ——**占领地/属地与本土当前同色**。
9. **[A] `USSR` 这个 key 同时承载 RSFSR 与苏联**：1920 年 `USSR` key 的 4 个 feature（`Georgia`/`Armenia`/`Azerbaijan`/`USSR`）→ 手工实体 `RU-RSFSR[[1917,1922]]`；1930/1938/1945/1960 → `RU-USSR[[1922,1991]]`。1945 年 `USSR` key 下还含 `Korea (USSR)` 与 `Germany (Soviet)`，当前与苏联本土同色。
10. **[A] 五个重点案例的「关键历史节点」大多落在两个快照之间**：Eritrea 的 1941–1952 BMA 期只有 **1945** 一个快照、且该 feature 的 raw key 是 `United Kingdom`（不是 `Eritrea`），当前 entityId 为 `UK-UNITED-KINGDOM`；1952–1962 联邦期只有 **1960** 一个快照（`ER-ETHIOPIA`）；**1962 年以后到 1993 年之间没有任何快照**（下一张是 1994）。Tanzania 的 1961/1963 边界、Zimbabwe 的 1923/1953/1965 节点同样都**没有对应快照**。→ 「哪些历史节点在当前数据中有可见表现」本身就是需要审查者知道的关键约束。

### 5.4 颜色机制

- 哈希函数是 **FNV-1a 32 位**（`scripts/lib/color.mjs:4` 注释 `/** FNV-1a 32 位哈希 */`，实现 `:5-12`）：偏移基 `0x811c9dc5`，质数 `0x01000193`，逐字符 `h ^= charCodeAt(i)` 后 `Math.imul`，末尾 `h >>> 0` 转无符号。
- `colorForKey(key)`（`:41-48`）：`!key` → `UNNAMED_COLOR`；否则 `h = fnv1a(key)`，`hue = h % 360`、`s = 0.34 + ((h>>>9)%5)*0.05`、`l = 0.6 + ((h>>>17)%4)*0.035`，经 `hslToHex(h,s,l)`（`:14-32`）输出 `#rrggbb`。
- 三层优先级（`scripts/lib/identity.mjs:245-292`，注释 `:247-251`）：①冻结注册表命中 → 直接复用（`:271-272`）；②`aliases.json` 显式 `color` → 用它（`:273`）；③保色实体（auto run 0，`legacy`）→ `colorForKey(hashInput)`，不探测（`:274`）；④其余（手工实体、auto run ≥1）→ 45° 窗口二次探测（`:278-289`）。
- 固定色 vs 哈希色：固定色来自 `entities[].color`（`identity.mjs:183` → `explicitColor`）与 `colors.json` 注册表（`identity.mjs:271`）；UNNAMED 使用固定中性灰 `#9aa0a6`（`color.mjs:35`），**不进注册表、不进 entities.json**（`scripts/verify-data.mjs:292-299`）。
- 撞色探测参数：`MAX_COLOR_PROBES = 256`（`identity.mjs:25`）、`CELL_DEGREES = 15`（`identity.mjs:22`）、3×3 邻域 = 45° 窗口（`identity.mjs:21,58-65`）。盐值递增方式为**哈希输入后缀** `${hashInput}#${salt}`（`identity.mjs:284`），不是对哈希值加减。
- 注册表只增机制实现位置：**写出侧** `scripts/build-data.mjs:480-494`；**读取侧** `scripts/build-data.mjs:275-276`。
- 生成结果落点：`data/identity/colors.json` 的 `colors` 字段（`:492`）；同一份颜色再注入 ① `public/data/years/*.json` 的 `properties.color`（`:431`）、② `public/data/entities.json` 的 `entities[].color`（`:505`）、③ `public/data/manifest.json` 的 `identity.distinctColors`（`:536`，只记数量）。
