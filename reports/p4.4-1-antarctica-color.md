# P4.4-1 南极洲颜色突变诊断报告（只读 · 未改任何代码）

- 阶段：P4.4-0 展示问题结案后的第二个排查项（User said m05486）
- 任务：对比 `public/data/years/world_1945.json` 与 `world_1960.json` 的南极洲 feature；检查 polity id / color 映射变化；判定是数据问题、规则问题还是渲染问题；**暂不修改代码**
- 本阶段至今**源码 0 改动 / 数据 0 改动 / 配置 0 改动**；只新增本报告

## 0. 结论摘要

1. **渲染层无责任。** `src/map/style.ts` 的 `historical-fill` 用 `'fill-color': ['get','color']` **逐 feature 取数据里的颜色**，渲染器不做任何取色判断；且 `public/data` 与 `dist/data` 的 54 个年份文件、54 个 relations、`manifest.json`、`entities.json` **全部 SHA-256 一致** → dev(5180) 与 preview(5181) 拿的是同一份数据，不存在「产物陈旧导致变色」。
2. **1945 与 1960 这两年的南极洲颜色其实完全相同**（都是 `auto:antarctica` / `#bbd086`）。真正的「突变」是：南极洲在 **1945、1960 两年是绿色 `#bbd086`**，在其余 **52 个快照里是中性灰 `#9aa0a6`（UNNAMED）**。切换时间轴时，颜色突变发生在 **1938 → 1945**（灰→绿）与 **1960 → 1994**（绿→灰）。
3. **根因 = 上游数据不一致（触发）+ identity 规则把非政权地理要素当成政权（放大）。** 上游 54 个原始文件里，南极洲要素只有 `world_1945.geojson` 与 `world_1960.geojson` 带有 `NAME/SUBJECTO/PARTOF = "Antarctica"`，其余 52 个文件这三个字段都是 `null`；而我们的身份解析规则是「`SUBJECTO || NAME` 非空即视为一个主体」，于是这两年产出独立实体 `auto:antarctica`，其余年份落入 `UNNAMED`。
4. 若要消除该视觉不一致，属于**数据/身份规则层**的改动，必然需要重建 `public/data/years/*.json`（命中 113 个保护文件）→ 需先单独报告并取得授权。本报告只做诊断，给出候选路径。

## 3. 上游原始数据证据（`data/raw/geojson/*.geojson`，54 个文件全扫）

| 文件 | NAME | ABBREVN | SUBJECTO | PARTOF | 构建后 entityId |
|---|---|---|---|---|---|
| `world_1945.geojson` | `"Antarctica"` | `""`（空串） | `"Antarctica"` | `"Antarctica"` | `auto:antarctica` |
| `world_1960.geojson` | `"Antarctica"` | `"Antarctica"` | `"Antarctica"` | `"Antarctica"` | `auto:antarctica` |
| 其余 52 个文件（含 `world_1938` / `world_1994` / `world_2010`） | `null` | `null` | `null` | `null` | `UNNAMED` |
| `world_800` / `world_900` / `world_1815`（旁证） | `null` | `"Antarctica"` | `null` | `null` | `UNNAMED` |

- 关键：`ABBREVN` 不参与身份判定，所以 800/900/1815 即便 `ABBREVN="Antarctica"` 仍是灰色 —— 这也反证了「是 SUBJECTO/NAME 的有无决定颜色」。
- 上游其它年份的属性键还有漂移（`INFO_UR`、`TYPE`、`type`、`weblnks/weblinks`、`CONTROL`、`fid`、1994 的 `BORDER_/BORDERI/FIPS_CO/WB_CNTR`），说明这个数据集的属性填充本身就不一致。

## 4. 规则链（代码路径与行号）

1. **取键**：`scripts/build-data.mjs:154` `const rawKey = p.SUBJECTO || p.NAME || null;`，`:155-157` 空 → `noKeyFeatures++`（即 UNNAMED）。
2. **归一化**：`scripts/lib/identity.mjs:35 normalizeKey()`（8 条纯格式规则，不做语义合并）。
3. **切分**：`scripts/lib/identity.mjs:129 splitRuns()`，阈值来自 `data/identity/aliases.json` 的 `gapSplitThreshold = 2`。1945 与 1960 在快照序列里相邻（1938→1945→1960），缺失数 0 → **不切分**，run 0 → `id = auto:antarctica`（`identity.mjs:210`）。
4. **取色**：`scripts/lib/color.mjs:41 colorForKey(key)` = FNV-1a 哈希 → HSL → `#rrggbb`；`colorForKey("Antarctica")` = `#bbd086`。空 key → `UNNAMED_COLOR = '#9aa0a6'`（`color.mjs:35`，其注释原文即写着「上游 NAME 为 null 的区域（**南极洲**、无人区等）使用中性灰」）。
5. **保色**：`auto` run 0 是「保色实体」（`identity.mjs:217 legacy: true`），`assignColors` 对它直接用公式色、**不做二次探测**（`identity.mjs:274`）→ 因此它的颜色永远等于 `colorForKey("Antarctica")`。
6. **没有被手工表覆盖**：`data/identity/aliases.json` 有 56 个手工实体，**没有任何** Antarctica 条目；`public/data/entities.json` 里南极洲只有一个实体：
   `{"id":"auto:antarctica","kind":"auto","label":null,"labelEn":null,"color":"#bbd086","keys":["Antarctica"],"periods":null,"years":[1945,1960]}`。

## 5. 判定：数据问题 / 规则问题 / 渲染问题

| 层 | 判定 | 依据 |
|---|---|---|
| 渲染 | **排除** | `src/map/style.ts` 的 `fill-color` 直接取 `feature.properties.color`；无按年份/按主体的条件着色；数据即真相 |
| 产物 | **排除** | `public/data` 与 `dist/data` 的 54 年份 + 54 relations + manifest + entities.json 逐文件 SHA-256 全等 |
| 上游数据 | **触发因** | 只有 1945、1960 两年给南极洲填了 NAME/SUBJECTO/PARTOF；其余 52 年为 null（同一要素、同一几何、同一 precision=3） |
| identity 规则 | **放大因** | 规则把「`SUBJECTO \|\| NAME` 非空」一律视为政权主体，缺少「非政权地理要素（南极洲、无人区、公海等）」白名单，于是把上游的属性噪声固化为一个只存在两年的实体与一套新颜色 |
| 关系层 | **无关** | 两年 sidecar 记录均为 `unresolved` 且不进入 properties |

一句话：**上游数据不一致是触发点，身份解析规则缺少非政权要素豁免是放大器，渲染与产物无关。**

## 6. 附带的两个「看着像 bug 其实不是」的现象

1. `#bbd086` 被 `auto:antarctica` 与 `auto:yurutí` 共用 —— 不变量 AR3（`scripts/lib/identity.mjs:12`）只要求**keys 有交集**的实体颜色不同，keys 不相交的实体允许同色；`auto:antarctica` 是保色实体，不参与探测。
2. 「只出现在极少数年份的实体」是普遍现象，南极洲只是最显眼（整块大陆）：`entities.json` 共 3,056 个实体，`years` 跨度 ≤2 的有 **1,876 个 auto 实体**（其中 1,600 个只出现 1 年）。若逐个「修正」会牵动整个身份模型，不宜作为本项修复手段。

## 7. 若要消除视觉突变：候选路径（**均需先授权，本阶段不实施**）

| 方案 | 做法 | 影响面 | 代价 |
|---|---|---|---|
| A. 规则豁免（推荐评估） | 在 identity 层对「非政权地理要素」加豁免（例如 bbox 完全位于 −60° 以南的要素强制 `UNNAMED`），使 54 年恒为灰 | 改 `scripts/build-data.mjs` / `scripts/lib/identity.mjs`（源码层，非保护文件），但需**重建** `public/data/years/*.json`（命中 113 个保护文件）→ 需重设基线 | 中：一次全量重建 + 基线重设 + 回归 19 项测试 |
| B. 手工实体 | 在 `data/identity/aliases.json` 增加一个 Antarctica 手工实体（固定灰、periods 覆盖全部年份） | 同上（仍在保护集外，但同样需要重建） | 中：语义上把一块非政权大陆登记为实体，需权衡 |
| C. 现状登记 | 不改数据，把该现象写入已知差异清单 | 仅文档 | 低，但用户每次切到 1945/1960 仍会看到变色 |

> 注：无论 A 或 B，都会改变 `public/data/years/*.json`、`public/data/entities.json`（保护集）→ 依既有治理规则，必须先报告取得授权，并同步重设 `tests/relations/run.mjs` 的基线。

## 8. 需要你确认的一点

构建产物里 **1945 与 1960 的南极洲同为 `#bbd086`**，两者之间没有颜色差异。如果你的观察是「1945 与 1960 彼此颜色不同」，那与当前产物不符（可能是浏览器缓存了旧的年份文件，或你看的是某一帧/悬停态）；如果你指的是「只在 1945 与 1960 这两年南极洲颜色与其它年份不同」——**已确认，且根因如上**。
