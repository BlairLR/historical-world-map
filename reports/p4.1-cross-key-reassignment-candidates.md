## §1 修正后的 sovereign / authority / relationship 数据模型

### 1.1 五层结构（取代上一版的四层）

```
feature        —— 几何 + 上游属性（NAME / SUBJECTO / PARTOF / ABBREVN / BORDERPRECISION）
  │  逐年解析（key = SUBJECTO || NAME）
polity         —— entityId：historical polity identity（唯一决定颜色的层）
  │
sovereign      —— sovereignId：法律意义上的主权者（de jure）
  │
authority      —— authorityId：当时实际行使控制、占领、军事管制或行政管理的一方（de facto）
  │
relationship   —— 单值枚举：polity 与 sovereign / authority 之间的法律关系
```

### 1.2 与上一版（已被 m01778 否决）的差异

| 上一版（`p4.1-sovereign-model-design.md` §1–§3） | 本版（修正后） |
|---|---|
| `sovereignId = 当时受哪个最高权力支配` | `sovereignId = 法律主权者`；**新增** `authorityId = 实际控制者` |
| 1945 Japan：`sovereign = USA` | `polity = JP-EMPIRE`，`sovereign = JP-EMPIRE`，`authority = US-USA`，`relationship = occupied` |
| 1941–1952 Eritrea：`sovereign = British Military Administration` | `sovereign = ∅`（无单值；见 §3），`authority = UK-BMA`，`relationship = administered` |
| `relationship` 允许复合值 `colony+protectorate` | `relationship` **单值**；同一 polity 同年不同法律关系由 **feature selector** 分开匹配 |
| `relationship` 14 值，含 `dominion` / `personal-union` / `chartered` | 收敛为 **11 值闭集**，剔除上述三项 |

### 1.3 字段定义

| 字段 | 类型 | 语义 | 缺省 |
|---|---|---|---|
| `entityId` | `string` | historical polity identity。**唯一决定颜色**。continuity 中断才新建 | 必填 |
| `sovereignId` | `string \| null` | 法律意义上的主权者。`null` = 无单值主权者 | 缺省 = `entityId`（该 polity 自身即主权者） |
| `authorityId` | `string \| null` | 当时实际行使控制/占领/军管/行政管理的一方。`null` = 无外部控制者 | 缺省 = `sovereignId`（无外部控制者时二者相同） |
| `relationship` | 11 值枚举 | polity 与 sovereign/authority 之间的法律关系（**单值**） | 缺省 = `sovereign-territory` |

**独立性判据（R2）**：polity 独立 ⇔ `sovereignId === entityId` **且** `relationship === 'sovereign-territory'`。

**关键点：`authorityId` 与 `sovereignId` 必须分开**，因此出现了四种组合（本轮实测均存在）：

| 情形 | Soviet | `sovereignId` | `authorityId` | 实例 |
|---|---|---|---|---|
| 本土 | = entityId | = entityId | 法国本土、日本本土 |
| 殖民地 | = 宗主 | = 宗主 | 英属香港、法属印度支那 |
| 占领地（主权未转移） | = 被占领的 polity 自身 | = 占领方 | 1945 日本（GHQ/SCAP）、1936–41 埃塞俄比亚 |
| 主权中断 / 共管 / 军管 | `null` | = 实际控制方 | 1945 德国（无条件投降）、英埃苏丹（共管）、厄立特里亚 BMA |

### 1.4 `relationship` 单值闭集（11 项）与判据

| 值 | 判据 | 本轮实测用例 |
|---|---|---|
| `sovereign-territory` | polity 自身即主权者，该多边形为其本土 | `Kingdom of Italy`（NAME 变体）、格鲁吉亚民主共和国 1920 |
| `colony` | 被外部主权者吞并/直接治理，无法理上的独立地位 | 英属香港、法属印度支那、荷属东印度、比属刚果（161 条） |
| `protectorate` | 保留内部自治与君主，对外关系由保护国代理 | 斯威士兰保护地、卡塔尔、特鲁西尔诸国（43 条） |
| `occupied` | 法理主权未正式转移，但领土被外部武力控制 | 1945 日本、1945 德国（各占区）、1936–41 埃塞俄比亚（8 条） |
| `dependency` | 低度自治的属地，无独立国际人格 | 冰岛/格陵兰（丹麦属地）、美属维尔京群岛（7 条） |
| `mandate` | 国际联盟委任统治地 | 巴勒斯坦、美索不达米亚、叙利亚（17 条） |
| `trusteeship` | 联合国托管地 | 意属索马里 1950–1960、英属喀麦隆、南太平洋委任统治地 |
| `autonomous` | 宗主国内部的自治单位/自治领，主权仍在宗主 | 南非联邦、纽芬兰自治领、香港特别行政区（5 条） |
| `condominium` | 两个及以上主权者共同行使主权 | 英埃苏丹、新赫布里底（3 条） |
| `administered` | 由外部方行使行政管理，主权归属另有安排或名义保留 | 埃及 1922 后（英军驻留）、费赞/昔兰尼加/的黎波里塔尼亚（军管）（8 条） |
| `unknown` | 上游数据不足以判定 | 本轮无需使用 |

**被剔除的三项（按 m01778 §3）的替代与遗留**：`dominion` → 暂用 `autonomous`（纽芬兰、南非联邦）；
`personal-union` → 本轮归入 **S 类暂缓**（`Hanover` 1715–1837 与英国君合、`Kingdom of Ireland` 1800 与英国君合）；
`chartered` → 本轮归入 **S 类暂缓**（`British East India Company` 下的 `India`/`Madras`/`Bengal`）。
这三项是 v2 扩展的第一批候选（见 §4.6）。

### 1.5 颜色规则：`color = f(entityId)` 不变（R1 / R2 / R3）

- **R1**：颜色只由 `entityId` 决定。`sovereignId`、`authorityId`、`relationship` **本身均不导致换色**。
- **R2**：只有 historical polity identity 确认发生连续性中断时，才新建 `entityId`（判据见 §1.3）。
- **R3**：同一个 `(key, year)` 允许承载**多个** polity（例如 1945 `United Kingdom` 的 24 个异名要素分属 12 个以上 polity）。
  这是 **feature selector 层**的放宽，**不改变** 颜色函数；`planEntities` 现有的
  `claim(nk, year, id)` 冲突检查（`scripts/lib/identity.mjs`）约束的是「同一 `(key, 年)` 不能被两个实体同时认领」，
  与 R3 不矛盾：R3 说的是 **polity 的归属可以按 feature 选择器分化**，而每个 feature 仍然只属于一个 polity。

**推论（也是本轮白名单的设计前提）**：把 1945 `Japan (USA)` 从 `US-USA` 改判到 `JP-EMPIRE`，**不**因为「美国控制了日本」而新建美国实体，也**不**因为「日本被占领」而给日本换色；颜色变化只来自 `entityId` 从 `US-USA` 变成 `JP-EMPIRE` 这一次身份更正。

### 1.6 存储形态（草案；本轮**不**创建，仅登记）

```jsonc
// data/identity/sovereignty.json —— 草案，键 = entityId
{
  "version": 1,
  "_note": "sovereign = 法律主权者，authority = 实际控制者；relationship 单值；区间可首尾相接但不可重叠",
  "UK-UNITED-KINGDOM": [
    { "from": 1707, "to": 2010, "sovereignId": "UK-UNITED-KINGDOM", "authorityId": "UK-UNITED-KINGDOM", "relationship": "sovereign-territory" }
  ],
  "HK-COLONY": [
    { "from": 1841, "to": 1997, "sovereignId": "UK-UNITED-KINGDOM", "authorityId": "UK-UNITED-KINGDOM", "relationship": "colony" }
  ],
  "JP-EMPIRE": [
    { "from": 1868, "to": 1944, "sovereignId": "JP-EMPIRE", "authorityId": "JP-EMPIRE", "relationship": "sovereign-territory" },
    { "from": 1945, "to": 1952, "sovereignId": "JP-EMPIRE", "authorityId": "US-USA",       "relationship": "occupied" }
```

③未登记的 `entityId` 按其 `relationship = sovereign-territory`、`sovereignId = authorityId = entityId` 解释（零配置默认）。

### 2.1 Sz（斯威士兰）

**发生了什么**：1894 年德兰士瓦与英国签订协定，斯威士兰由德兰士瓦行使保护与管理权（1894–1899）；1899–1902 第二次布尔战争期间英国接管；1903 年正式转归英国，1906 年成为英国保护地，1968 年独立。

**是否构成新 historical polity**：**否**。斯威士兰王国（恩格温亚马王朝）在此过程中持续存在，变化的是**外部控制者**（斯威士兰王室 → 德兰士瓦 → 英国），不是 polity 的连续性。这正是 m01778 §1 要区分的 `authority` 层。

**对现有 P4.1 实现的影响**：P4.1 第二轮把这段实现了 **3 段**：`SZ-KINGDOM[[1750,1902]]`、`SZ-PROTECTORATE[[1903,1967]]`、`SZ-ESWATINI[[1968,2010]]`。
按 polity 原则，前两段**应当是同一个 polity**（区别只在 `authorityId`），因此现在的切割是「以控制权变化冒充政权变化」，与原则冲突。
按 m01778 §4 的指令，**本轮不实施合并**，留待下一轮单独裁定；本文件只登记该冲突。

**建议（待裁定）**：合并为 `SZ-KINGDOM[[1750,1967]]`（保持 `SZ-KINGDOM` 的颜色），并在 sovereignty 层写 `1894–1902 authorityId = ZA-TRANSVAAL`、`1903–1967 authorityId = UK-UNITED-KINGDOM`。

### 2.2 Sierra Leone

**发生了什么**：1808 年弗里敦一带成为英国皇家殖民地（Crown Colony）；1896 年内陆各部族地区成为英国保护地（Protectorate）；两者由同一总督治理，1961-04-27 独立。

**是否构成新 historical polity**：**否**。1896 年的「殖民地 → 保护地」是**同一政体内的法律关系分化**，不是政权连续性中断。

**建议**：保持 `SL-COLONY[[1808,1960]]` 连续。**relationship 必须允许不同 feature 在不同阶段分别表示**：
1896 年前的沿海要素 = `colony`；1896 年后的内陆要素 = `protectorate`。这正是 m01778 §3「relationship 保持单值、用 feature selector 分开匹配」的典型用例。

**本轮实测**：`Sierra Leone` 在 1815/1878/1880/1900/1914/1920/1930/1960 快照中作为 `United Kingdom` key 下的候选出现 8 次（共 7 个要素变色到 `SL-COLONY`），各年覆盖范围不同。

**是否应换色**：否。

### 2.3 Tanzania

**发生了什么**：德属东非（1919 后为英属坦噶尼喀托管地）；坦噶尼喀 1961-12-09 独立、1962-12-09 成为共和国；桑给巴尔 1963-12-10 独立；1964-04-26 坦噶尼喀与桑给巴尔合并，1964-10-29 定名坦桑尼亚联合共和国。

**是否构成新 historical polity**：**1961 是**殖民 → 独立的真正边界；**1963 不是** Tanzania polity 的边界（桑给巴尔独立是另一个 polity 的事件）。

**建议**：`TZ-TANGANYIKA[[1919,1960]]` + `TZ-TANZANIA[[1961,2010]]`（把 `TZ-TANZANIA` 的起点由现在的 1964 提前到 1961）。
**理由**：现状把 1961–1963 的独立坦噶尼喀算作殖民政权 `TZ-TANGANYIKA`，语义错误。
**但**：54 个快照的年份序列为 … 1960 → 1994 → 2000 → 2010（**没有 1961–1993 之间的任何快照**），
因此该修正在当前快照集上**零要素影响**：1960 及以前仍命中 `TZ-TANGANYIKA`，1994 及以后仍命中 `TZ-TANZANIA`，两段的可见归属完全不变。
按 m01778「暂不拆生产 entity」，本轮不动，仅登记为「语义修正、零观测影响」的待办项。

### 2.4 Zimbabwe

**发生了什么**：1890 年英属南非公司占领；1923 年南罗得西亚成为英国自治殖民地（责任政府）；1953–1963 年与北罗得西亚、尼亚萨兰组成中非联邦；1965-11-11 UDI（白人少数政权单方面宣布独立）；1980-04-18 独立为津巴布韦。

**是否构成新 historical polity**：1923、1953 **否**（自治地位与联邦安排都是宗主国内部/跨领地的行政安排）；1965 UDI **pending**。

**建议**：1923、1953 不拆；UDI 保持 pending —— 不立即新建 polity、不立即换色，只在 sovereignty 层记录 1965–1979 的 `authorityId`（白人少数政权）与 `relationship = autonomous`（或 `unknown`）。

**是否应换色**：否。

## §3 Eritrea 专项建议（1952 / 1962 问题）

### 3.1 时间线（权威事实）

| 阶段 | 年份 | legal sovereign | administering authority | relationship |

| 意属殖民地 | 1890–1941 | 意大利王国 | 意大利王国 | `colony` |
| 英国军事管制（BMA） | 1941–1952 | **∅**（1947 和约放弃意大利主权，归属未决；联合国 1950 决议） | 英国军事管制当局（BMA） | `administered` |
| 与埃塞俄比亚联邦 | 1952–1962 | 埃塞俄比亚皇帝（联邦元首） | 厄立特里亚自治政府 + 联邦机构 | `autonomous` |
| 埃塞俄比亚直辖省 | 1962–1991 | 埃塞俄比亚 | 埃塞俄比亚 | `administered` |
| EPLF 实际控制 | 1991–1993 | ∅（过渡） | 厄立特里亚人民解放阵线（EPLF） | `administered`（无快照年） |
| 独立 | 1993– | 厄立特里亚 | 厄立特里亚 | `sovereign-territory` |

### 3.2 当前实现的问题

现有的 `ER-ETHIOPIA[[1952,1992]]`（P4.1 第二轮为 T1 的 `eritrea` 建立）把 **联邦自治（1952–1962）** 与 **直辖省（1962–1991）** 合成**一个** entity，并且用**埃塞俄比亚**为其命名。
在 polity 语义上，这等于宣称「1952–1992 的厄立特里亚是埃塞俄比亚这个 polity 的一部分」，而这与史实不符：
1952–1962 年厄立特里亚是一个**有自己宪法、议会与旗帜的自治单位**（联邦制下的政治实体），1962 年才被降格为省。
按 m01778 §4.5 的要求「1952–1962 联邦自治阶段与 1962 以后埃塞俄比亚直辖阶段必须在 sovereignty/relationship 语义上区分」，
`ER-ETHIOPIA[[1952,1992]]` **是下一轮 P4.1 的修正候选**（本轮不动）。

### 3.3 三个维度分开记录（1952–1962 vs 1962–1991）

| 维度 | 1952–1962 | 1962–1991 |
|---|---|---|
| legal sovereign | 埃塞俄比亚皇帝（**联邦**关系，非单一主权） | 埃塞俄比亚（**单一主权**） |
| administering authority | 厄立特里亚自治政府（内部自治）+ 联邦政府 | 埃塞俄比亚中央政府 |
| relationship | `autonomous` | `administered` |

**这三行是本节的核心结论**：两个阶段的差异**不在 `sovereignId` 的唯一性**（两段名义主权者都是埃塞俄比亚），
而在 `relationship` 与 `authority`（自治 vs 直辖）。这正是把 `authorityId` 独立出来的价值 —— 如果只有四层模型（polity→sovereign），
这两段无法区分，只能要么合并（现状，语义错），要么错误地宣称 1952 年厄立特里亚已完全独立。

### 3.4 1941–1952 BMA：本轮不认定为新 polity

按 m01778 §4.5 第 3 点：**只作为 sovereignty/authority/relationship 阶段记录，不立即认定为新的 historical polity，不立即换色。**
本轮白名单中已按此登记（附录 A 第 29、126 行）：

- `year = 1914`（key `Italy`）/ `year = 1945`（key `United Kingdom`）的 `Eritrea`
- `proposed entityId = ER-BMA`（新建候选，**标注为 P1 修正候选、本轮暂不实施**）
- `proposed sovereignId = ∅`、`proposed authorityId = UK-BMA`、`proposed relationship = administered`

（注意：1914 年的 `Eritrea` 应归 `ER-COLONY`（已存在，意属殖民地 1890–1941），不是 BMA —— 白名单中已按年份区分。）

### 3.5 下一轮的具体建议（三选一，推荐 B；**本轮不实施**）

| 方案 | 内容 | 换色影响 | 评价 |
|---|---|---|---|
| **A** | 保持 `ER-ETHIOPIA[[1952,1992]]` 不变，只在 sovereignty 层记录 1952–1962 = `autonomous` | 零 | 语义仍混（entity 名与 label 都是「埃塞俄比亚」），但零风险 |
| **B（推荐）** | 拆成 `ER-FEDERATION[[1952,1962]]`（`rel = autonomous`，`sovereign = ET-EMPIRE`，`authority = ER-FEDERATION`）与 `ER-PROVINCE[[1962,1993]]`（`rel = administered`，`sovereign = ET-EMPIRE`，`authority = ET-EMPIRE`）；同时把 `ER-COLONY[[1890,1941]]` 与 `ER-BMA[[1941,1952]]` 补齐 | 1960 快照的 1 个厄立特里亚要素由 `ER-ETHIOPIA` 改判为 `ER-FEDERATION` → **1 个要素换色** | 语义最正确：把「联邦自治」与「直辖省」按 polity 连续性判据分开；新增 `ET-EMPIRE`（当前无此 manual 实体） |
| **C** | 只改 `ER-ETHIOPIA` 的 `label`/`periods`，不拆 entity | 零 | 不推荐：混合语义只是被改名掩盖 |

**推荐 B 的理由**：m01778 明确要求「1952–1962 与 1962 以后必须在 sovereignty/relationship 语义上区分」；
若只在 sovereignty 层区分（方案 A），则 `entityId` 仍把两段视为同一 polity，与「relationship 不同 = 法律关系不同」的原则不自洽 —— 但**是否必须换色**属于 polity 连续性判断，需要用户裁定。

**因此这一项需要用户在下一轮明确裁定**：1952 年联邦化是否构成厄立特里亚 polity 的连续性中断？

**要求的动作（下一轮）**：`data/identity/aliases.json` 增加 `ER-BMA`、`ER-FEDERATION`、`ER-PROVINCE`、`ET-EMPIRE`；`ER-ETHIOPIA` 退役或改期为 `[[1962,1993]]`；新增 `data/identity/sovereignty.json` 登记 BMA 与联邦两段。

## §5 风险与未决问题

1. **98 个新 manual entity 的粒度问题**：`FR-AOF`（法属西非）、`FR-AEF`（法属赤道非洲）、`IN-BRITISH-RAJ`（英属印度）这类「行政集合体」在 polity 语义上是**一个 polity** 还是**多个 polity 的集合**？按最严格的原则，法属西非下辖 8 个殖民地，各自是不同 polity；但它们在快照中是单个多边形、单个 NAME。**需要用户裁定**。
2. **`relationship` 与换色的边界**：本模型明确「relationship 不自动换色」，但当同一 `entityId` 下 relationship 从 `colony` 变成 `sovereign-territory`（例如某殖民地独立），实际必然换色。因此**规则实际上是**：`entityId` 变化才换色，而 relationship 变化**是**判定 `entityId` 是否应当变化的输入之一 —— 二者是「判据」与「结果」的关系，不是两条独立规则。**需要在实施文档中写清，避免被误读为「relationship 可以独立触发换色」**。
3. **1914 年埃及**：上游把 1914/1920 的埃及放在 `United Kingdom of Great Britain and Ireland` 下（保护国），1930 年也在英国 key 下（但已是独立王国）。白名单按年份分别给出 `EG-PROTECTORATE` / `EG-KINGDOM`，但 1930 年快照把独立埃及放在英国 key 下这一事实本身是**上游归类问题**（类似 X 类），需在实施时确认是否同时修正 key。
4. **`auto:` 实体与新 manual 实体的关系**：白名单中 256 条 R 类的 `authority` 大量指向 `auto:france`、`auto:netherlands`、`auto:portugal`、`auto:italy`、`auto:belgium`、`auto:spain#1`、`auto:denmark#1`。实施时需要决定：是否把这些 `auto:` 升级为 manual（如 `FR-KINGDOM`、`NL-REPUBLIC`、`PT-KINGDOM`、`IT-KINGDOM`、`BE-KINGDOM`、`ES-HABSBURG`、`DK-KINGDOM`）。
   **注意**：按现有构建规则，manual 实体的 `hashInput` 是自己的 id（`scripts/lib/identity.mjs:181` `hashInput: id`），而 auto 实体 run 0 用原始拼写（`scripts/lib/identity.mjs:216` `hashInput: k === 0 ? raw : \`${raw}#${k}\``），
   因此把 `auto:X` 升级为 manual `Y` **会改变颜色**；若不希望换色，需要在 `aliases.json` 里为升级后的 manual 实体显式指定 `color`（`entities[].color` 支持固定值），或保留 `auto:` id。详见 `DESIGN-P4.1-entity-identity.md`。
