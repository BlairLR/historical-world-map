## §A 当前系统能力边界（只读实测）

**运行形态**：纯静态 Vite 站点 + `public/data` 静态 JSON；无服务端、无底图、离线可用。`src/` 共 **12 个文件 / 1,734 行 / ≈44 KB**（`App.tsx` 206、`loadYear.ts` 125、`snapshots.ts` 58、`types.ts` 112、`MapView.tsx` 249、`TimeBar.tsx` 276、`timelineLabels.ts` 131、`authorityLabels.ts` 30、`map/style.ts` 80、`map/graticule.ts` 25、`main.tsx` 12、`styles.css` 430）。

**数据面（恰好 3 条 fetch 路径）**

1. `manifest.json`（15,510 B）—— `src/data/snapshots.ts:11`，进程内只请求一次（`manifestPromise`）。
2. `years/world_<year>.json`（54 个 / 43,512,416 B）—— `src/data/loadYear.ts:40`；LRU `MAX_CACHED_YEARS = 6`（`:11`、`:50`）。
3. `relations/<year>.json`（54 个 / 2,358,028 B）—— `src/data/loadYear.ts:98`；独立 `relationCache`/`relationInflight`（`:73-74`），`MAX_CACHED_RELATIONS = MAX_CACHED_YEARS`（`:71`）；**404 → `null` 且不算错误**（`:100-103`），失败只在 `src/App.tsx:78` 记 `console.warn` 并降级。

**状态与数据流**：`yearIndex: 0..53` 为状态真相（`src/App.tsx:18`）；`year` 仅用于显示与 URL（`:88` → `writeYearToUrl`）；`?year=` 初始经 `findIndexByYear()` 吸附（`:37`）；`setData()` 仅两处（`src/components/MapView.tsx:168` 挂起帧、`:240` 数据变更）；关系层变化只更新 ref（`:221-223`），**永不进入 `setData`/GeoJSON**。

**渲染面**（`src/map/style.ts`，单一 source `historical` + 4 图层）：`ocean` 背景 `#dbe6f2`；`graticule` 经纬网（`src/map/graticule.ts` 构建期生成）；`historical-fill`（`fill-color: ['get','color']`；`fill-opacity` 按 `precision` 1/2/3 → 0.55/0.7/0.85）；`historical-outline`（统一 `#4b5563` / 0.4px / 0.6，**与关系无关**）；`historical-hover`（`#0f172a` / 2.2px，由 `feature-state.hover` 驱动）。

**交互面**：hover 命中 `FILL_LAYER_ID` → `setFeatureState` 高亮（`MapView.tsx:183-202`）+ 手写 DOM tooltip（`renderTooltip` `:82`）；时间轴自研（`TimeBar.tsx` + `timelineLabels.ts` 占位区间避让防重叠）；播放节奏 `BASE_DWELL_MS = 900 / speed`（`App.tsx:13`、`:137`，**与真实年份跨度无关**）；倍率 0.5/1/2/4（`:27`）；键盘 ←/→（`:154-165`，输入框内不触发）；URL `?year=` 双向同步。

**明确不具备的能力**：无底图/卫星图；无国家搜索；无详情面板；无图例（原 P3 的 `Legend` 从未建）；无密度条；无历史事件层；无 3D（从未调用 `setProjection`）；无 AI 查询（无 `server/`）；无二进制格式 / Worker / 预取；无自动化 `npm test`；**relationship 目前只影响 tooltip 文案，不影响任何视觉编码**。
