# 快照源数据与几何管线修复（2026-11-08）

本轮处理：公元前 323/300 年和 1600 年朝鲜重叠、1994 年附近切换闪现重复台湾、100 年政权名 `1`、1938 年楚科奇东端缺失、太平洋群岛及俄北岛屿缺失、1960 年千岛群岛缺失。

## 原因与处理

|问题|已核实原因|修复所在层|
|---|---|---|
|朝鲜前 323/300 年|无名背景要素重复覆盖，原重叠约 8.6997 平方经纬度|构建阶段将重叠背景 dissolve，不把无名背景当作彼此不同的政权|
|朝鲜 1600 年|具名 Korea 的粗轮廓与无名南部沿海细几何重复，叠加之外还存在沿海灰带|地理模型明确朝鲜王朝时期（1404–1897，含济州纳入后的范围）；只有快照已有 Korea 且无名几何与经过核查的沿海参考完全一致时，继承该年原生 Korea 属性，再按相同证据合并几何。不会把现代韩国身份带入古代，也不改变北方陆上边界|
|台湾与瞬时闪回|1994 上游两份粗细轮廓；此前前端过滤使用新年份配旧数据，加载期间撤销过滤|数据构建时按同一身份、相同证据、强双向重叠、明显分辨率差异识别重复；保留细几何。删除前端 `prepareMapData` 及年份/ID 特例。加载结果绑定自身年份，关系层也只与相同已加载年份配对|
|100 年政权 `1`|原始 SUBJECTO 为字符串 `1`，PARTOF 为 `true`|通用字段校验排除纯数字、布尔及空占位符。同期另一非法身份 `auto:3` 也由同一规则移除；不冒猜为某个国家|
|1938 楚科奇缺角|日期变更线西经一侧的独立多边形缺失，不是投影裁切|从已锁定来源提取完整地理组件，仅补快照缺少的陆地；1938 年按 USSR 已知控制记录赋色|
|太平洋、俄北岛屿及千岛|原始快照缺少物理陆地组件，上游并未提供稳定地理底层|新增独立地理参考目录，参考几何和历史控制分开声明；计算缺失覆盖，而非复制邻年整个国家|

## 数据模型与边界

- `data/geo/land-regions.json` 声明参考来源、空间选择范围、适用年代、明确的控制时间段和 SHA-256。窗口仅用于选择**完整**地理组件，不沿矩形手工画疆域。来源改变会停止构建并要求重新核查。
- 来源是 `aourednik/historical-basemaps@4b5039e50d8d2464b065bd76ad6086cd4597108d` 的现有原始数据。参考几何来自 1920、1938、1945、1994 与 1600 年文件；只复用物理几何，政治身份由目标年代的声明或原生证据决定。
- 俄北地理参考从 1938 年起启用；1938/1945/1960 使用 USSR，1994/2000/2010 使用 Russia。没有将 1920 年控制关系自动外推到其他古代年份。
- 新喀里多尼亚保持法国身份；瓦努阿图 1980 年独立前为英法共管，不能照抄来源中的 France 单一主权标签。独立前保留中性地理范围，1994 起使用 Vanuatu 身份。
- 所罗门**群岛地理范围**横跨多个现代辖区，不能把整片地理群岛当成同一个国家；本轮恢复物理岛屿，未核定部分保留中性颜色。
- 千岛分为北部和南部四岛组：1960 年北部使用 USSR；缺失的南部争议岛组保留中性地理范围，不为整条岛链猜测主权。现有年份具名政治记录不会被参考层自动覆盖。
- 新增 `geographicName`，与 `entityId` 分开保存；悬浮提示明确地理参考并非主权裁定。
- 具体历史控制时间段是可审查的声明，不等于完整历史事实审计。物理参考采用相邻年代海岸线，并不能表达所有填海、冲淤或海平面变化。

## 实现与验证

- `scripts/lib/source-normalization.mjs`：输入字段校验、同证据几何归并、背景拓扑与政治覆盖优先级；没有年份/feature ID 特例。
- `scripts/lib/reference-land.mjs`：物理组件来源校验、缺失陆地计算和显式控制规则。
- `scripts/build-data.mjs`：身份规划和写出共用同一份校验后输入，重算几何统计，输出 `public/data/normalization-audit.json`。
- `scripts/verify-data.mjs`：增加非法名称回归断言。
- `tests/map/source-normalization.test.mjs`：源字段与不可变性、背景面积守恒、朝鲜拓扑、台湾细轮廓、朝鲜沿海唯一身份、现代代表点覆盖与控制／争议边界等回归。
- 关系测试继续逐记录检查保守性；背景合并改变记录数后，T9 的旧固定总数改为对输入字段独立计数，不用新的固定数字替换旧数字。
- 多边形运算依赖固定版本 `polygon-clipping@0.15.7`，已更新锁文件。前端不承担地理修补。
- 已进行八个代表视图的 Chromium 放大检查，且人为延迟年份请求 450ms 后，在 1960、1994、2000 间往返七次；每次传给地图的数据均只有一份台湾几何，没有页面脚本错误。

上游 55 个原始文件保持原 SHA-256；本轮明确重新生成派生年份文件、实体索引、manifest 和关系 sidecar，不能再将派生文件描述为未变化。已有冻结颜色保留，仅增加 Vanuatu 注册项。修复与 Preview 验证完成时未提交或推送 GitHub，也未初始化项目或保存、发布云环境配置；后续 Git 交付以实际提交记录为准。

完整本机证据在 `/workspace/.onboarding-tools/geo-review/`，包括构建、数据校验、几何测试、关系测试、浏览器结果及放大截图。最终测试与预览发布结果由本轮回复给出。
