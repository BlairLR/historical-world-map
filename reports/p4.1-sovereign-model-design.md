三条主结论：

1. **`entityId` 保持不变**，它继续且只表达 **polity（历史政权）**；颜色仍只由 polity 决定。
2. `sovereign` 与 `relationship` 是**正交的新维度**，加在 feature 上（不是替代 `entityId`）。本轮它们**不参与任何配色计算**。
3. 造成「《United Kingdom》在 1938/1945 只有殖民地要素」这类问题的根因不是颜色算法，而是**上游 `SUBJECTO` 一个字段同时承担了「我是谁」和「我归谁」两种语义**；实测证据见 §2。修法是把语义拆开，而不是继续拆 entity。

## §1 四层语义

### 1.1 定义

| 层 | 回答的问题 | 决定颜色？ | 当前对应物 | 建议载体（新增） |
|---|---|---|---|---|
| **feature** | 「这块多边形在某个快照年里是什么」 | 否 | GeoJSON Feature（`properties`） | 不变 |
| **polity** | 「它当时是哪个**历史政权**」 | **是（唯一决定者）** | `properties.entityId` | 不变 |
| **sovereign** | 「它当时受哪个**最高权力**支配」 | 否（本轮）/ 将来影响透明度 | 无（被混进 key） | `properties.sovereignId` |
| **relationship** | 「以什么**法律关系**被支配」 | 否（本轮）/ 将来影响纹理 | 无 | `properties.relationship` |

```
GeoJSON feature ──被判定为──▶ polity (entityId) ──唯一决定──▶ color
        │
        └──同时被判定为──▶ sovereign (sovereignId) ◀──由── relationship 描述
```

### 1.2 三条硬规则

- **R1（配色独立性）**：`color = f(polity)`，与 `sovereign` / `relationship` **完全无关**。同一 polity 换宗主不换色（如 1902 年斯威士兰从德兰士瓦保护地转为英国保护地）。
- **R2（本体自反）**：polity 若是独立政权，则 `sovereignId === entityId` 且 `relationship === "sovereign-territory"`。这让「独立/被支配」可以由机器判定。
- **R3（多 polity 共存）**：同一个 `(上游 key, 快照年)` **允许承载多个 polity**，只要 feature 级选择器能区分。这条放宽了现有 `(key, year)` 唯一性约束，但**只放宽到 feature 层**（见 §3.4）。

### 1.3 为什么不能继续用拆分 entity 的办法解决

拆分 entity 会**改变颜色**，而「美国 1945 年同时有本土、日本占领区、德国占领区、朝鲜占领区、美属维尔京群岛」这件事里，**真正需要新颜色的只有「美属维尔京群岛」（一个 dependency）**；日本/德国/朝鲜在 1945 年是**被占领国**，它们的 polity 是日本/德国/朝鲜（各自有自己的历史政权），只是当时 sovereign 是美国。用拆 entity 的办法处理，会把「占领」错误地编码成「新的历史政权」，正是政权原则要避免的。

## §2 实测证据：`entityId` 为什么混合了两个语义

### 2.1 机制

`scripts/build-data.mjs:154`：

```js
const rawKey = p.SUBJECTO || p.NAME || null;
```

**`SUBJECTO` 优先**。于是：

- 一个主权国家的本土要素：`NAME=Luxembourg | SUBJECTO=Luxembourg` → key = `luxembourg`。
- 一个殖民地要素：`NAME=Sierra Leone | SUBJECTO=United Kingdom` → key = `united kingdom`。

同一个字段，两种语义。`scripts/lib/identity.mjs:155` 的 `planEntities()` 又只按 `(归一化 key, 年份)` 认领身份（`entityOfYear: Map<key, Map<year, entityId>>`，冲突即抛 `身份冲突`），所以**同一 key 同一年不可能落在两个 polity 上**，殖民地只能被宗主吞掉。

### 2.2 后果的实测规模

| 快照年 | key | 要素数 | 其中「本土」要素 | 其余是什么 |
|---|---|---|---|---|
| 1938 | `united kingdom` | 20 | 1（`NAME=United Kingdom`） | 19 = 殖民地/保护地/托管地/占领地 |
| 1945 | `united kingdom` | 25 | 1（`NAME=United Kingdom`） | 24 = 同上 |
| 1945 | `usa` | 5 | 1（`NAME=United States`） | `Japan (USA)` / `Germany (USA)` / `Korea (USA)` / `United States Virgin Islands` |
| 1945 | `ussr` | 3 | 1（`NAME=USSR`） | `Korea (USSR)` / `Germany (Soviet)` |
| 1938 | `italy` | 5 | 2（`NAME=Italy` ×2） | `Eritrea (Italy)` / `Ethiopia (Italy)` / `Italian Somaliland` |
| 1914 | `italy` | 4 | 1（`Kingdom of Italy`） | `Eritrea` / `Libya` / `Italian Somaliland` |

1938 年 `united kingdom` 的完整成员（实测 `NAME`）：
`United Kingdom` · `Sierra Leone` · `Tanzania, United Republic of` · `Northern Rhodesia` · `Southern Rhodesia` · `Botswana` · `Swaziland` · `Lesotho` · `Gold Coast` · `Malaysia` · `Nigeria` · `Kenya` · `Uganda` · `Yemen (UK)` · `British Somaliland` · `Walbis Bay` · `Oman (British Raj)` · `British Raj` · `Gilbert and Ellice Islands` · `Hong Kong`

→ **同一 polity（英国）在 1938 年同时是 1 个本土 + 19 个性质完全不同的属地**：直辖殖民地、保护地、保护国、委任统治地、自治领、租借地。它们的 `relationship` 各不相同（`colony` / `protectorate` / `mandate` / `dominion` / …），但在当前模型里**全部是同一个 `entityId`、同一种颜色**。

### 2.3 反向证据：同一 territory 在不同年份被写进不同 key

| territory | 出现在 `SUBJECTO=Eritrea` 的年份 | 出现在 `SUBJECTO=Italy` 的年份 |
|---|---|---|
| 厄立特里亚 | 1920, 1930（+ 1960 在 `Eritrea`） | **1914**（`NAME=Eritrea`） |

| territory | 自己 key 的年份 | 只在 `SUBJECTO=United Kingdom` 下出现的年份 |
|---|---|---|
| Sierra Leone | 1815,1878,1880,1900,1914,1920,1930,1960,1994,2000,2010 | **1938, 1945** |
| Nigeria / Kenya / Uganda / Botswana / Lesotho / Swaziland / Tanzania / Northern Rhodesia / Southern Rhodesia / Gold Coast | 至 1960 | **1938, 1945** |

→ 「殖民地在 1938/1945 年凭空消失」不是数据缺失，而是**上游把归属字段填成了宗主国**。这些年份里它们以 `NAME=<本国名>` 存在于宗主国的 key 之下。

### 2.4 `NAME` 也不能当历史依据

`zimbabwe` key 在 **1920 / 1930 / 1960** 的 `NAME` 是 `Zimbabwe`——而「Zimbabwe」是 1980 年才有的国名，1920 年的正确名称是 Southern Rhodesia。同理 `tanzania, united republic of` 在 1920/1930/1960 的 `NAME` 是 `Tanzania, United Republic of`（1964 年才成立）。**上游用现代国名指代殖民时期领地，是系统性约定，不是偶发错误**（本项目 `reports/p4.1-reaudit-polity.md` §0 已记录）。

### 2.5 `PARTOF` 也不能承担 containment

| 情形 | 实测例子 | 说明 |
|---|---|---|
| `PARTOF` = 自身 NAME | `NAME=Sierra Leone \| SUBJECTO=United Kingdom \| PARTOF=Sierra Leone`（1938） | 与 SUBJECTO 自相矛盾 |
| `PARTOF` = 宗主 | `NAME=Dominion of Newfoundland \| PARTOF=United Kingdom of Great Britain and Ireland`（1920/1930） | 真正的 containment |
| `PARTOF` = 宗主（联邦/帝国级） | 1900 年澳洲各州 `PARTOF=United Kingdom of Great Britain and Ireland` | 真正的 containment |
| `PARTOF` = null | `NAME=Hong Kong \| PARTOF=<null>`（1878–1938） | 无信息 |

→ `PARTOF` 是**弱且不一致**的 containment 信号，只能作为 feature 选择器的**辅助匹配项**，不能作为模型主干。

### 2.6 `SUBJECTO` 至少有四种互相冲突的含义

以 1800 年的 `uk` key 为例（`SUBJECTO` 全部是 `UK`）：

| `NAME` | 实际关系 | `SUBJECTO` 在这里的含义 |
|---|---|---|
| `United Kingdom` | 主权国自身 | 我就是 UK |
| `British Guiana` | 直辖殖民地 | 我归 UK |
| `Hanover` | **君合国**（1714–1837 与英国共主） | 我与 UK 共戴一君 |
| `Kingdom of Ireland` | **共主邦联/合并前的独立王国**（1801 年前） | 我与 UK 共戴一君 |
| `Mecklenburg-Strelitz` | 与英国无宗主关系 | **无法解释（疑上游错误）** |

→ 结论：`SUBJECTO` 在语义上是不可靠的。要表达「受谁支配、以什么方式支配」，必须由我们**人工维护一张 `relationship` 表**，而不是从上游字段推断。

## §3 最小 sovereign / relationship 数据模型

设计目标：**最小、纯增、可回滚、零颜色变化。**

### 3.1 标识符规则

- **`polityId`**：沿用现有 `entityId`。形态不变：手工 `UK-UNITED-KINGDOM`，自动 `auto:ethiopia` / `auto:uganda#1`，兜底 `UNNAMED`。
- **`sovereignId`**：两种形态。
  - sovereign 本身是被建模的 polity → **直接复用其 `polityId`**（`UK-UNITED-KINGDOM`、`RU-USSR`、`US-USA`、`auto:italy`、`auto:ethiopia`）——注意自动实体的 id 形如 `auto:<key>`。好处：「谁是 A 的宗主」可以纯机器遍历，不需要额外映射。
  - sovereign 没有被建模为 polity → **`SOV:` 前缀**，避免与 polity 命名空间冲突。首批需要的：`SOV:GB-CROWN`（英国王室，区别于 UK 这个 state）、`SOV:ZA-ZAR`（南非共和国/德兰士瓦）、`SOV:BSAC`（英国南非公司）、`SOV:GB-BMA`（英国军事管制）、`SOV:UN`（联合国）、`SOV:RHODESIA-NYASALAND-FEDERATION`（罗得西亚与尼亚萨兰联邦）、`SOV:ANGLO-EGYPTIAN`（共管）。
- **`relationship`**：**闭集枚举**，见 §3.2。禁止自由文本。

### 3.2 `relationship` 闭集（14 值）

| 值 | 含义 | 实测例子（全部来自本轮探针） |
|---|---|---|
| `sovereign-territory` | 本体国土，polity 即主权者 | 1815 `NAME=United Kingdom \| SUBJECTO=United Kingdom` |
| `colony` | 殖民地，主权在宗主，本地无主权 | 1938 `NAME=Sierra Leone \| SUBJECTO=United Kingdom`；1914 `NAME=Eritrea \| SUBJECTO=Italy` |
| `protectorate` | 保护地，保留本地统治者，外交/国防归宗主 | 1938 `Swaziland` / `Botswana` / `Lesotho` / `British Somaliland`（均 `SUBJECTO=United Kingdom`）；1894–1902 斯威士兰（德兰士瓦） |
| `occupied` | 军事占领地 | 1945 `Japan (USA)` / `Germany (USA)` / `Korea (USA)` / `Germany (Soviet)` / `Cyraneica (UK Lybia)` |
| `dependency` | 附属领地（非本土、非典型殖民地建制） | 1945 `United States Virgin Islands`；`Hong Kong`（1878–1993）；1878/1880 `Iceland` / `Greenland`（`SUBJECTO=Denmark`） |
| `mandate` | 国际联盟委任统治地 | 1920/1930 `Mandatory Palestine (GB)`；`Mesopotamia (GB)` |
| `trusteeship` | 联合国托管地 | 1945 `NAME=Tanzania, United Republic of \| SUBJECTO=United Kingdom`（Tanganyika Trust Territory） |
| `dominion` | 自治领 | 1920/1930 `Dominion of Newfoundland`；1914 `South Africa` |
| `autonomous` | 联邦内自治单位 | 1952–1962 厄立特里亚（与埃塞俄比亚联邦）；1953–1963 南罗得西亚（联邦成员） |
| `condominium` | 共管 | 1914 `Anglo-Egyptian Sudan` |
| `chartered` | 特许公司治理 | 1890–1923 南罗得西亚（英国南非公司） |
| `personal-union` | 君合（共戴一君，各自独立） | 1800 `Hanover`；1800 `Kingdom of Ireland`（均 `SUBJECTO=UK`） |
| `administered` | 国际/军事管制，无主权者 | 1941–1952 厄立特里亚（BMA，1947 年意大利放弃主权后无主权国） |
| `unknown` | 无法判定（兜底） | — |

> 说明：`disputed`（主权有争议/未获承认）本轮暂不纳入，因为唯一候选（1965–1979 罗得西亚 UDI）会与 polity 判定纠缠（见 §4.4）。若你同意把它作为 `relationship` 而非 polity，再加第 15 个值。

### 3.4 三层解析（与现有代码的对接点）

| 层 | 输入 | 输出 | 现有实现 | 改动 |
|---|---|---|---|---|
| **L1 polity** | `(归一化 key, 年)` | `polityId` | `planEntities()` → `entityOfYear: Map<key, Map<year, entityId>>` | **不改** |
| **L2 sovereign** | `(polityId, 年)` | `sovereignId` + `relationship` | 无 | 新增，纯查表 |
| **L3 feature 细化** | `(key, 年, name, partOf, subject)` | 覆盖后的 `polityId` + `sovereignId` + `relationship` | 无 | 新增，在写 feature 时应用 |

关键设计点：

1. **L1 的唯一性约束保持原样**。`claim()` 仍然在 `(key, year)` 上抛冲突。这样 Step A 期间不会影响任何现有 polity 与颜色。
2. **只有 L3 放宽到 feature 层**，且冲突检测下沉为 `(key, year, selector)`。两个 `featureRule` 若 selector 有交集 → 构建期报错。这样「同一 key 同一年两个 polity」从「禁止」变成「必须用 selector 证明可区分」。
3. **L3 在 Step A 只赋 `sovereignId`/`relationship`，不改 `entityId`**；改名/拆 polity 是 Step B 的事（见 §6）。
4. L2/L3 的匹配失败一律 fallback 到 `relationship: "unknown"`，**不报错、不改色、不阻断构建**——保证纯增量。

## §4 §8 五项历史边界判读（只判读，不修改）

> 以下所有「当前实现」数字来自 `data/identity/aliases.json` 与 `public/data/entities.json`。

### 4.1 Sz（斯威士兰 / Eswatini）—— 1894–1902 是否需要拆出布尔控制段

**发生了什么**

| 年 | 事件 |
|---|---|
| ~1750 | 恩格瓦尼（Ngwane）王朝建立斯威士兰王国；19 世纪 40 年代姆斯瓦蒂二世完成整合 |
| 1881 / 1884 | 比勒陀利亚公约、伦敦公约：名义上承认斯威士兰独立，同时承认德兰士瓦的特殊利益 |
| 1890–1894 | 德兰士瓦（南非共和国，ZAR）行政与租让权持续侵入 |
| **1894-12** | **英-德兰士瓦公约：斯威士兰置于南非共和国"保护"之下**（非兼并；斯威士国王保留对内（Swazi law and custom）权力，对外事务归 ZAR） |
| 1899–1902 | 第二次布尔战争 |
| **1902 / 1903** | 德兰士瓦被英国兼并；斯威士兰转为**英国保护国**（1903 年起由南非高级专员管辖；1906 年脱离德兰士瓦行政） |
| 1910 | 南非联邦成立，斯威士兰未被并入，保持高级专员领地地位 |
| 1963 / 1967 | 宪法、内部自治（君主立宪） |
| **1968-09-06** | **独立，斯威士兰王国** |
| 2018-04-19 | 改名 Eswatini（**仅国名变化**） |

**判读**

| 项 | 结论 |
|---|---|
| 1894–1902 是否构成新的 historical polity | **否**。斯威士兰王国作为 polity 连续存在；改变的是 **sovereign（自身 → 南非共和国）** 与 **relationship（sovereign-territory → protectorate）**。保护国在国际法上保留被保护国的国际人格，这是 sovereign 维度的教科书案例。 |
| 建议 entityId | 不新增。1894–1902 用 `SZ-KINGDOM` + `sovereignId: "SOV:ZA-ZAR"` + `relationship: "protectorate"` 表达 |
| 建议 periods | `SZ-KINGDOM` 建议改为 `[[1750,1967]]`（见下）；`SZ-PROTECTORATE` 建议**并入** `SZ-KINGDOM` |
| 是否应该换颜色 | **1900 → 1914 不应换色**。当前 `SZ-KINGDOM (1878/1880/1900)` 与 `SZ-PROTECTORATE (1914–1960)` 是两种颜色，属于「把宗主变更编码成政权变更」；按政权原则应**合并为同一 polity、同色**。1894→1902 的布尔段在本判读下也**不换色**。 |
| 置信度 | 日期与史实：**高**。「1894–1902 不是新 polity」：**中高**。「1903 年保护地不是新 polity（应与王国同色）」：**中**（这是本项唯一有可见换色后果的建议，需你确认） |
| 附带 | `SZ-ESWATINI (1994–2010)` 的 label 应改为「斯威士兰王国」——2018 年改名是**名称变化**，已在同一 polity 内，无需换色。⚠️ 注意：**改 entityId 会改颜色**（颜色由 id 的哈希决定），所以只建议改 label，不建议改 id。 |

### 4.2 Sierra Leone —— 1808–1896 海岸殖民地 vs 1896–1960 保护地是否属于不同 polity

**发生了什么**

| 年 | 事件 |
|---|---|
| 1787 / 1792 | 自由省 / 弗里敦（塞拉利昂公司） |
| **1808-01-01** | 公司领地移交英国王室 → **塞拉利昂直辖殖民地（Crown Colony）**，仅限弗里敦半岛与邻近岛屿 |
| 1808–1896 | 内陆为**独立的非洲诸政权**（滕内、门德、科亚、洛科、谢尔布罗、林巴等） |
| **1896-08-31** | **内陆保护地（Protectorate）宣告成立**（1898 年茅屋税战争后确立） |
| 1896–1961 | 「塞拉利昂殖民地与保护地」由同一总督治理，但**法律上殖民地与保护地长期分立** |
| 1951 | 宪法把殖民地与保护地统一为单一立法机构 |
| **1961-04-27** | 独立（自治领）；1971 年改共和 |

**判读**

| 项 | 结论 |
|---|---|
| 1808–1896 vs 1896–1960 是否属于不同 polity | **否**（就「英属塞拉利昂」这个政治实体而言）。sovereign 未变（英国王室），治理主体未变（塞拉利昂总督），行政连续。变化有二：**(a) 领土扩张**（把内陆非洲诸政权纳入保护地），**(b) 内陆部分的法律地位**从「独立政权」变为「保护地」。(a) 按政权原则不换色；(b) 属于 **relationship / 领土内部构成**，不是 polity 变更。 |
| 建议 entityId | 不新增。`SL-COLONY` 保持单一 polity |
| 建议 periods | `SL-COLONY [[1808,1960]]`（**保持现状**）；`SL-SIERRA-LEONE [[1961,2010]]`（保持现状） |
| 是否应该换颜色 | **不换**。1896 年落在快照 1880 与 1900 之间，本来也无可见后果 |
| 表达方式 | `politySovereignty["SL-COLONY"]` = `{1808–1895: colony}` + `{1896–1960: colony+protectorate}`（或两条记录，见 §3.3 注） |
| 置信度 | 日期：**高**；单一 polity 判读：**中高** |
| **重要实测附带发现** | 1938 与 1945 年，`sierra leone` key **完全不存在**；塞拉利昂多边形出现在 `SUBJECTO=United Kingdom` 之下（`NAME=Sierra Leone \| PARTOF=Sierra Leone`）。所以「塞拉利昂的政治身份在这两年丢失」是**跨 key 问题**，不是 periods 问题——它需要 §3.4 的 L3 feature 规则，而不是改 `SL-COLONY` 的 periods。同样的两年缺口同时影响 Nigeria / Kenya / Uganda / Botswana / Lesotho / Swaziland / Tanzania / Northern & Southern Rhodesia / Gold Coast（见 §2.3）。 |

### 4.3 Tanzania —— 1961 还是 1963 作为政权边界更合理

**发生了什么**

| 年 | 事件 |
|---|---|
| 1919 / 1922 | 坦噶尼喀领地（Tanganyika Territory），英国委任统治（国联） |
| 1946 | 改为联合国托管地，仍由英国管理 |
| **1961-12-09** | **独立**——坦噶尼喀成为独立国家（自治领，女王为国家元首，尼雷尔任总理） |
| **1962-12-09** | **改共和**——同一国家、同一政府，**国家形式**由自治领变为共和国 |
| **1964-04-26** | **与桑给巴尔合并**，成立「坦噶尼喀与桑给巴尔联合共和国」 |
| **1964-10-29** | 改名「坦桑尼亚联合共和国」（**仅国名变化**） |

**判读**

| 项 | 结论 |
|---|---|
| 哪个年份是政权边界 | **1961 是「殖民政权 → 独立政权」的政权边界**（坦噶尼喀领地 vs 坦噶尼喀国）。**1963 不是任何意义的边界**——坦噶尼喀自 1961 年起已独立，1963 年只是桑给巴尔独立、联邦解体的邻近事件。唯一另一个真实边界是 **1964（联合共和国成立）**。 |
| 1962 改共和算什么 | **不是新 polity**（同一国家、同一政府、同一领土），是 **sovereign 变更**（英王 → 本国人民）→ 归入 sovereign 维度 |
| 建议 entityId | `TZ-TANGANYIKA-TERRITORY`（殖民）· `TZ-TANGANYIKA`（独立 1961–1963）· `TZ-TANZANIA`（1964 起联合共和国）。但见下「实施约束」 |
| 建议 periods | 理想：`TZ-TANGANYIKA-TERRITORY [[1919,1960]]` / `TZ-TANGANYIKA [[1961,1963]]` / `TZ-TANZANIA [[1964,2010]]`。**实施约束**：`TZ-TANGANYIKA [[1961,1963]]` 覆盖 0 个快照年份（快照在 1960 与 1994 之间无点），会被 `scripts/lib/identity.mjs:232-235` 当作零要素实体丢弃。因此现状 `TZ-TANGANYIKA [[1919,1963]]` + `TZ-TANZANIA [[1964,2010]]` **行为上完全等价**，只是 `TZ-TANGANYIKA` 的语义标签把「殖民 + 独立」混在了一起。 |
| 是否应该换颜色 | 就当前 54 个快照而言：**不该换**（1960 是殖民地 → 殖民色正确；1994+ 是联合共和国 → 现有色正确）。若将来增加 1962 快照：**应该换**（独立坦噶尼喀不应与殖民坦噶尼喀同色）。 |
| 置信度 | 1961 是殖民/独立边界：**高**。1963 无意义：**高**。1964 是联合共和国边界：**高**。 |
| 建议动作 | 本轮**不改**。建议仅在 `aliases.json` 的注释/`label` 里写清 `TZ-TANGANYIKA` = 「坦噶尼喀（领地 + 独立国，1919–1963）」，并登记一条待办：**若快照年份集扩展，必须在此处拆三段**。 |

### 4.4 Zimbabwe —— 1923 / 1953 / 1965 三个节点分别发生什么，哪些真正应该产生新 polity

**发生了什么**

| 年 | 事件 |
|---|---|
| 1890 / 1893 / 1898 | 英国南非公司（BSAC）占领马绍纳兰、马塔贝莱兰；1898 年命名为 Southern Rhodesia |
| **1922** | 全民公决选择自治而非并入南非 |
| **1923-10-01** | BSAC 特许状终止；南罗得西亚**并入王室，成为自治殖民地（responsible government）** |
| **1953-09-01** | **罗得西亚与尼亚萨兰联邦**成立（南罗得西亚 + 北罗得西亚 + 尼亚萨兰）；南罗得西亚**保留自己的政府与议会** |
| **1963-12-31** | 联邦解散，南罗得西亚回到自治殖民地状态 |
| **1965-11-11** | **单方面独立宣言（UDI）**，史密斯政府自称「Rhodesia」，否认王室权威，国际未承认 |
| 1970-03-02 | 依 1969 年宪法成为共和国 |
| 1979-06-01 | 「Zimbabwe Rhodesia」（内部和解） |
| **1980-04-18** | **独立，Zimbabwe** |

**逐节点判读**

| 节点 | 是不是新 polity | 建议 entityId | 建议 periods | 是否换色 | 置信度 |
|---|---|---|---|---|---|
| **1923**（公司 → 王室自治殖民地） | **否**。南罗得西亚这个殖民地连续存在，主权者始终是英国王室；变的只是**治理主体**（BSAC → 王室/自治政府） | 不新增 | `ZW-SRHODESIA` 建议 `[[1890,1964]]` | 不换 | 中（有一种可辩护的读法是把 BSAC 时期视为独立 polity，类比刚果自由邦；但 BSAC 是**依特许状代表王室**治理，与刚果自由邦的君主私人领有性质不同，故建议不拆） |
| **1953**（联邦成立） | **对 Zimbabwe 多边形：否**。南罗得西亚作为殖民地继续存在并保留自己的政府。联邦是**更高一层**的政治结构 | 不新增 polity；在 sovereign 层记录 `SOV:RHODESIA-NYASALAND-FEDERATION` + `relationship: "autonomous"` | — | 不换（1930 与 1960 同色） | 中高（1930 与 1960 分处联邦成立前后，是唯一有可见后果的一对——建议不换） |
| **1965**（UDI） | **边界情形，倾向「是」**。王室权威被公开否认，最高权力的实际行使者从王室/总督变为罗得西亚阵线政府；这正是「政权」的定义性变化。反方论点是行政机构与领土完全连续，只是主权主张变了 → 归 sovereign 维度 | 若采纳：新增 `ZW-RHODESIA [[1965,1979]]`；若不采纳：`sovereign: "SOV:RHO-PROVISIONAL"` + `relationship: "disputed"`（需扩充枚举） | `ZW-SRHODESIA [[1890,1964]]` / `ZW-RHODESIA [[1965,1979]]` / `ZW-ZIMBABWE [[1980,2010]]` | **当前无可见后果**（`zimbabwe` key 年份 = 1920/1930/1960/1994/2000/2010，1965–1979 无快照）。若将来加入 1970 快照：**应该换** | **中**（这是五项中置信度最低的一项，也正是建议把它当作 sovereign 层而非 polity 层的原因） |
| **1980**（独立） | **是** | `ZW-ZIMBABWE [[1980,2010]]` | 保持现状 | 换 | 高 |

**实测附带发现（对本项很关键）**：`zimbabwe` key 在 **1920 / 1930 / 1960** 三年的 `NAME` 已经是 `Zimbabwe`（1980 年才有的名字），`SUBJECTO`、`PARTOF`、`ABBREVN` 也全是 `Zimbabwe`。→ **上游快照完全不携带 1920/1930/1960 三者的任何区分信息**，Southern Rhodesia / 联邦成员 / 三者的法律地位差异都必须由我们自己的历史表（而非上游字段）提供。这直接支持 §3 的设计：**relationship 必须人工维护**。

### 4.5 Eritrea —— 意属殖民地 → 埃塞俄比亚统治 → 独立；1941–1952 BMA 是否应成为独立阶段

**发生了什么**

| 年 | 事件 | 主权者 | 建议 relationship |
|---|---|---|---|
| **1890-01-01** | **意属厄立特里亚殖民地成立**（colonia primogenita） | 意大利 | `colony` |
| 1936–1941 | 并入**意属东非**（Eritrea + Ethiopia + Italian Somaliland），厄立特里亚仍为独立总督区 | 意大利 | `colony`（联邦层可另记） |
| **1941-04/05** | 英军攻占（克伦战役、阿斯马拉），**英国军事管制（BMA）** | 英国（军事管制） | `occupied` / `administered` |
| **1947-02-10** | 对意和约：**意大利放弃对厄立特里亚的主权** → 此后**无主权国**，由四国/联合国处理 | 无 → 联合国 | `administered` |
| **1952-09-15** | **与埃塞俄比亚联邦**：厄立特里亚为自治单位，有自己的宪法、议会、政府；埃塞俄比亚皇帝为国家元首 | 埃塞俄比亚（联邦） | `autonomous` |
| **1962-11-14** | 埃塞俄比亚议会表决**兼并**；厄立特里亚降为**省**（Governorate-General），议会解散 | 埃塞俄比亚（直辖） | `administered` / 兼并省 |
| 1961–1991 | 独立战争（ELF → EPLF） | — | — |
| **1991-05-24** | EPLF 攻占阿斯马拉，**事实上独立** | 自身（未获承认） | `sovereign-territory`（过渡） |
| **1993-05-24** | 联合国监督公投后**正式独立** | 自身 | `sovereign-territory` |

**判读**

| 项 | 结论 |
|---|---|
| 意属殖民地（1890–1941） | **是独立 polity** → 现有 `ER-COLONY [[1890,1941]]`（建议 label 改为「意属厄立特里亚」），`sovereign: auto:italy`，`relationship: colony`。置信度**高** |
| **1941–1952 BMA 是否应成为独立阶段** | **建议是，但用 sovereign/relationship 表达为主**。理由：① 主权者在 1941 年从意大利变为英国军事管制，1947 年又变为「无主权国 / 国际处理」，**主权链条断裂**；② 该期间厄立特里亚**没有任何本地自治政府**，与前后两段都不同质；③ 现状是 `ER-COLONY [[1890,1941]]` 与 `ER-ETHIOPIA [[1952,1992]]` 之间**存在 1941–1951 的空档**，任何落在该窗口的快照都会掉到 `auto:` 实体。→ 建议 `ER-BMA [[1941,1952]]`，`sovereign: SOV:GB-BMA → SOV:UN`，`relationship: occupied → administered`。**颜色**：倾向换色（意向性：敌国殖民地 → 军事占领/国际管制），置信度**中高**（存在「polity 仍是厄立特里亚这块地，只有主权者变了」的保守读法，此时只记 sovereign 而不换色） |
| 与埃塞俄比亚联邦（1952–1962） | **是独立 polity** → `ER-FEDERATION [[1952,1962]]`，`relationship: autonomous`，`sovereign: auto:ethiopia`。**1960 快照落在此区间**，当前被 `ER-ETHIOPIA` 认领 → **label 与史实不符**（1960 年是联邦，不是埃塞俄比亚直辖）。建议换色。置信度**高** |
| 埃塞俄比亚省（1962–1991） | **是独立于联邦的阶段** → `ER-PROVINCE [[1962,1992]]`，`relationship: administered`（兼并省）。置信度**高**（阶段存在与定性）；**是否换色**：倾向是，置信度**中** |
| 独立（1991/1993–） | `ER-ERITREA`。建议 `[[1993,2010]]`（正式独立），1991–1993 记为 `relationship: transitional` 或 `disputed`。置信度**高** |
| **对现有 P4.1 的具体影响** | ① `ER-ETHIOPIA [[1952,1992]]` 语义应拆为 `ER-FEDERATION [[1952,1962]]` + `ER-PROVINCE [[1962,1992]]`；② 补 `ER-BMA [[1941,1952]]`；③ 其中 `ER-PROVINCE` 与 `ER-BMA` 在现有快照集里**零年份**，会被 builder 丢弃 → 这正是应该把它们先写进 `sovereignty.json` 而**暂不作为 polity** 的理由（§3.7 AR15） |
| **实测附带发现** | 1914 年厄立特里亚多边形**不在 `eritrea` key 下**，而在 `SUBJECTO=Italy` 之下（`NAME=Eritrea`）；1920/1930 才转到 `SUBJECTO=Eritrea`。→ 意属殖民地 polity 跨 key（`Eritrea` + `Italy`）可达，需要 §3.4 L3 的 `(key, name)` 选择器，而不是改 periods |

## §5 对现有 P4.1 是否需要修改的建议

### 5.1 建议保持不动（明确）

| 对象 | 理由 |
|---|---|
| `overrides.mergeRuns = ["Pagan","Pandya state"]` | 唯一真正适用 mergeRuns 的两个案例（同一政权跨数据空档），已验收 |
| `UK-UNITED-KINGDOM`（keys: United Kingdom / UK of GB and Ireland / UK） | 你的 m01734 §4 明确要求暂时保持不动；语义问题交由 sovereign 层解决 |
| `US-USA`（keys: United States / USA / United States of America） | 同上 |
| `RU-RSFSR` / `RU-USSR` | D1 方案，已验收 |
| `DK-NORWAY` / `SE-NORWAY` | 双元王国按独立政权处理，已验收 |
| 全部 14 组 E 类实体（`DZ-*`…`VI-*`） | 政权转换分段，已验收 |
| `overrides._reviewQueue`（Denmark / Norway / Bhutan / Cyprus） | 你的 m01734 §2 明确保持不动；38 个 B 类不处理 |

### 5.3 关于 builder 是否需要改动

**Step A 不需要改 `scripts/build-data.mjs` / `scripts/lib/identity.mjs` 的核心逻辑**，只需：

1. 读入 `data/identity/sovereignty.json`；
2. 写 feature 时按 L2/L3 附加 `sovereignId` / `relationship` 两个字段；
3. `verify-data.mjs` 增加 AR11–AR15。

`planEntities()` 的 `(key, year)` 唯一性约束、`splitRuns()`、`assignColors()`、`colors.json` 只增机制**全部不动**。这是「最小」的具体含义。

**唯一需要注意的实现细节**：`scripts/lib/identity.mjs:232-235` 会丢弃零要素实体（`if (ent.years.length === 0) entities.delete(id)`）。sovereignty 层**不经过这条路**，所以年份为空的历史结构（BMA、罗得西亚 UDI、坦噶尼喀独立段）可以安全地先写在 sovereignty 文件里而不会引起构建告警。

### 5.4 结论

**现有 P4.1 在 polity/颜色这个层面不需要返工。** 你在 m01734 §4 要求的「先通过 sovereign/relationship 模型解决语义问题」是正确的路径：§2 的证据表明，1938/1945 的「英国只有殖民地没有本土」不是 entity 划分错误，而是**上游归属字段被当成了身份键**。拆 entity 是对症状下药，会污染 polity 语义（把占领地、保护地、自治领、君合国都变成「新政权」）。
