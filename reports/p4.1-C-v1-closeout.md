## 4. 明确未处理

1. **manifest 接线 OQ-B2** — 暂缓。`public/data/manifest.json` 无 relations 字段，`scripts/lib/relations-build.mjs` 不写 manifest；前端由 `snapshot.year` 直接推导 `relations/<year>.json` URL，因此 B2 对当前读取路径并非必需。若将来启用，`public/data/manifest.json` 属受保护文件，需显式授权并重设基线。
2. **历史实体模型问题** — 例如 `Japan (USA)`：年份文件中 `entityId = US-USA`、`subject = USA`、`partOf = Japan (USA)`，即 1945 年占领期的身份归属直接落在占领方 polity 上；V1 不做身份层改造、不改 entityId、不动 `data/identity/**`。
3. **Egypt / Anglo-Egyptian Sudan / Hawaii** — 明确未处理（未写规则、未新增 authority）；另 Hawaii 1898–1959 在 54 个快照中不存在对应记录。
4. **authority 数据扩展** — 未做。现状：`colony` / `mandate` / `trusteeship` / `autonomous` / `sovereign-territory` 的 `authorityId` 全为 `null`（对应规则只写 `sovereignId`），故这些类型在 V1 tooltip 中「治理主体」显示 `—`；是否需要补 `authorityId` 属历史裁决，本轮不处理、不改数据。
5. **sovereign UI** — V1 不展示 `sovereignId`；字段保留在数据层，未新增任何关于 `sovereignId` 的展示或约束。

同时保持 OPEN（不因本报告关闭或合并）：OQ-B2/B3 之外的全部仍开放 OQ 与决策衍生项（`OQ-3`、`OQ-4`、`OQ-6`、`OQ-9`、`OQ-11`~`OQ-14`、`OQ-C1`~`OQ-C5`、`C5-D1`、`C5-D2` 等，权威清册见 `reports/p4.1-C-pilot-batch-1-coverage.md` §16 与 `docs/design/P4.1-C-OQ-decisions.md`）。
